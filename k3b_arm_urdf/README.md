# K3B 机械臂 URDF

依据淘宝在售「6 自由度舵机机械臂 DIY 套件」实物结构 + 各舵机厂商三维图建模。

## 执行器映射（实测 2026-10-25）

| 舵机 | 型号 | 类型 | 脉宽范围(μs) | 上电初始 | URDF 关节 | 作用 | 限位(相对直立位) |
|---|---|---|---|---|---|---|---|
| S1 | S20F | 180° 位置 | 850–1500 | 850 | `finger_left_gear_joint` | 夹爪开合（输出轴带齿轮） | 0 ~ 55° |
| S2 | S20F | 180° 位置 | 500–2500 | 1500 | `base_yaw` | 底座偏航 | ±90° |
| S3 | S20F | 270° 位置 | 500–2000 | 2000 | `shoulder_pitch` | 肩俯仰 | ±101° |
| S4 | S20F | 270° 位置 | 500–2500 | 500 | `elbow_pitch` | 肘俯仰 | ±135° |
| S5 | PM15S | 270° 位置 | 600–2500 | 1500 | `wrist_pitch` | 腕俯仰 | ±128° |
| — | DS3120 | 360° 连续 | — | — | `wrist_roll` | 夹爪旋转 | 无限位(continuous) |

- 夹爪是一条四连杆，**只有 `finger_left_gear_joint` 接 S1**；其余 5 个关节全是 `<mimic>`，
  由它按固定倍率带动（倍率由孔位反解得到，不是拍脑袋的 ±1）。
- `wrist_roll` 是速度舵机，无位置反馈，URDF 中为 `continuous`，**MoveIt 规划时要 disable 该关节**。
- **S5（PM15S）三维图暂缺**，当前以其 S20F 270° 版代替，待实测后替换网格与限位。

## 关节结构

| 关节名 | 类型 | 轴 | 舵机 | 说明 |
|---|---|---|---|---|
| `base_yaw` | revolute | Z | S2 | 底座偏航 |
| `shoulder_pitch` | revolute | Y | S3 | 肩俯仰 |
| `elbow_pitch` | revolute | Y | S4 | 肘俯仰 |
| `wrist_pitch` | revolute | Y | S5 | 腕俯仰 |
| `wrist_roll` | continuous | Z | DS3120 | 夹爪旋转，控速不控位 |
| `finger_left_gear_joint` | revolute | Y | **S1** | 输入杆：齿轮扇形板，0 ~ 55°（0.95993 rad） |
| `finger_left_joint` | revolute | Y | mimic | 指片（coupler），相对齿轮臂 −1.12343 |
| `finger_left_bar_joint` | revolute | Y | mimic | 平行连杆（rocker2），+0.94140 |
| `finger_right_gear_joint` | revolute | −Y | mimic | 右齿轮扇形板，×1（啮合齿轮反向） |
| `finger_right_joint` | revolute | −Y | mimic | 右指片，−1.12343 |
| `finger_right_bar_joint` | revolute | −Y | mimic | 右平行连杆，+0.94140 |

末端工具坐标系：`tool0`（落在爪尖，`gripper_base` 上方 82mm）。

**全关节为 0 = 直臂垂直 + 夹爪合拢**，上表限位均相对该位姿定义。

> **夹爪机构**：S1 输出轴带一只齿轮，与对称侧的齿轮扇形板啮合 —— 一对齿轮转向相反，
> 所以右指整条链取 `axis = (0 −1 0)`，倍率与左指相同，天然镜像。
> 逆时针（CCW）张开、顺时针（CW）闭合。每侧由 4 根杆闭合：
> `机身—G—齿轮臂—A—指片—B—平行连杆—R—机身`，实测杆长
> **rocker1 29.98 / coupler 21.01 / rocker2 29.96 / ground 22.34 mm**。
> 按 Grashof：最短(coupler 21.0) + 最长(rocker1 30.0) = 50.99 < 其余两杆 52.29，
> 且最短杆是 coupler → **双摇杆机构**，齿轮臂只摆动不整圈，与实拍一致。
> 网格由 `part_claw.stl` 按运动副拆成 7 块，见下方「机械爪拆分」。

### 机械爪拆分

`part_claw.stl` 是 21 个零件叠起来的一坨刚性网格——直接挂上去只能看，不能开合。
`tools/split_claw.py` 先按连通分量把 21 个零件分开，**再按运动副归堆成 7 块**：

| 归属 | 零件 | 判据（面数；同型号件面数完全相同，比包围盒稳） |
|---|---|---|
| `claw_body` | 背板(3040) + 舵盘夹(1112×2) + 垫块(504×4) + 小垫块(368×3) | → 8,384 |
| `claw_finger_*` | 指片 7398×4（左右各 2 片） | → 14,796 / 侧 |
| `claw_gear_left` | 齿轮圆盘(3036) + 带齿臂(1360) | → 4,396 |
| `claw_gear_right` | 带齿臂(1360) —— **本模型只有一片圆盘** | → 1,360 |
| `claw_bar_*` | 平行连杆 708×4（左右各 2 片） | → 1,416 / 侧 |

输出面数校验：**合计 46,564 = 原文件 46,564** ✓，连通分件 21 个、输出 7 个文件。

```bash
python tools/split_claw.py k3b_arm_urdf/meshes/part_claw.stl
```

> **杆长是反解出来的，不是量出来的**：`tools/claw_4bar.py` 用「STL 内部孔洞检测」
> （flood fill 外部 + 内部连通域）读出所有销孔坐标，再按**孔位共点**关系拼出拓扑：
> `#5 与 #7 中心孔` → G；`#7 与 #0 共用孔` → A；`#0 与 #10 共用孔` → B；
> `#10 与 #4 共用孔` → R。四杆闭合、长度自洽，说明拆件和拓扑判断都对。
>
> 半侧坐标系 `(u, v)`：u = 到对称面 `X = 2.75mm` 的距离（向外为正），v = claw 网格 Z。
> 解算用**圆-圆交点法**：给定输入角 θ，先由 G→A 定出 A 点，B 点 = `圆(R, rocker2) ∩ 圆(A, coupler)`；
> 指片转角由两销点 (A,B) 的相对朝向求刚体旋转。扫 0→55° 得开合曲线，再拟合成 `<mimic>` 倍率：

| 量 | 值 | 说明 |
|---|---|---|
| `lim_gear` | 0.95993 rad (55°) | S1 行程上限 |
| `mimic_finger` | −1.12343 | 指片相对齿轮臂（父杆已转 θ，取的是**相对角**） |
| `mimic_bar` | +0.94140 | 平行连杆相对机身（父杆是机身，绝对角即关节值） |

> **为什么不是漂亮的 −1**：`<mimic>` 只能线性，而四连杆的真解是三次曲线。
> 这里取「端点精确」——55° 处的开度与轴向位置与反解完全一致，中段留残差（最大约 2mm）。
> 要彻底消掉得换 `ros2_control` 自定义 controller，或在 MoveIt 里用真连杆插件替换线性近似。

| 状态 | 爪距（内） | 齿轮中心 → 爪尖（轴向） |
|---|---|---|
| 合拢（齿轮 0°） | **7.50 mm** | **84.30 mm**（实测 7.5 / 85） |
| 全开（齿轮 55°） | **41.92 mm** | **67.96 mm**（实测 55 / 70） |

⚠ **开度差 13mm**：实测内距 55mm，模型 41.9mm；但轴向 68.0 ↔ 实测 70 基本对上。
把齿轮推到机构硬极限 80°，内距也只有 47.1mm —— 即「内距 55 且轴向 70」在这套爪形下不能同时成立，
大概率实测量的是爪尖**外角**或齿口而非内角。轴向对上说明杆长本身没错，暂锁 55° 等复测。

> 另一个待查点：整爪 21 个分件里**只有一片齿轮圆盘**（3,036 面，落在左侧），右侧只有带齿臂。
> 若实物是两片对称圆盘，说明厂商模型少画了一片 —— 不影响杆长反解（A/B/R 都来自共点销孔），
> 但张开时右齿轮那里会显得薄。

**夹爪四连杆**（半侧，单位 mm；由 `tools/claw_4bar.py` 从 STL 孔位反解，不是卷尺量）：

| 杆 | 端点 | 长度 |
|---|---|---|
| rocker1（齿轮臂） | G → A | **29.98** |
| coupler（指片） | A → B | **21.01** |
| rocker2（平行连杆） | R → B | **29.96** |
| ground（机身） | G → R | **22.34** |

Grashof：`21.01 + 29.98 = 50.99 < 29.96 + 22.34 = 52.30`，且最短杆是 coupler

两段臂长实测值代回去，全零总高 **54.5 cm**，与卷尺量到的「约 55 cm」自洽 ✓

```bash
# 若改过 xacro，先重新展开
xacro k3b_arm.urdf.xacro > k3b_arm.urdf
```

## MoveIt2

```bash
ros2 run moveit_setup_assistant moveit_setup_assistant
```

导入 `k3b_arm.urdf`，规划组：

- `arm`：5 个转动关节（base_yaw → wrist_roll）
- `gripper`：**只放 `finger_left_gear_joint`**（revolute 0~0.95993 rad）。
  其余 5 个关节都是 mimic，会自动跟随，**不要再加进组里** —— 加进去会让解算器当成独立自由度。
  如果 MoveIt 的 `mimic` 支持没打开，就在 `joint_limits` 里把 5 个从动件设成
  `passive`，或直接把它们的 `limit` 收紧到 `0 0` 当固定件用（仍然是正确的视觉姿态）。

**注意**：`wrist_roll` 是速度舵机、无位置反馈，逆解时把它设为 **passive/disable**，
否则解算器会分配自由度给它，实机却执行不了。

## ⚠️ 实机前仍需校准

1. **杆长**：`upper_arm_len` / `forearm_len` 已实测填入；还需补 `wrist_len` 与 `base_height`
2. **直立位对应脉宽**：上表给的是量程和上电值，还缺「直立时各舵机的脉宽」——这是下位机做
   `脉宽 → 关节角` 标定的关键，务必实测记录
3. **真实质量/惯量**：Gazebo 物理仿真前必须填写
4. **S5 / PM15S**：拿到三维图后替换网格，并按实测修正 `lim_wpitch`
5. **夹爪开度复测（最优先）**：模型全开内距 42mm ↔ 实测 55mm，但两者轴向 70mm 都对得上。
   需确认 55mm 量的是**爪尖内角**还是外角/齿口 —— 若确实是内角，说明销孔反解有偏差，
   届时重跑 `tools/claw_4bar.py`，用它打印的 `gap` 列反查实测内距 55mm 对应的齿轮角。
6. **`<mimic>` 是线性近似**：`mimic_finger`/`mimic_bar` 按 55° 端点精确拟合，
   中段与真四连杆有 ≤2mm 的残差。要精确就用 `ros2_control` 自定义 controller 走 `claw_4bar.solve()`。
7. **S1 方向**：确认实机 850→1500μs 对应 **CCW = 张开**；若反了，把 `lim_gear` 下限并取负、
   或在下位机取反脉宽映射。
