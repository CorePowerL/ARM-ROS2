# 三维图预览（viewer3d）

用浏览器直接看 STEP 模型，不用装 SolidWorks / Fusion。

- **解析**：`occt-import-js`（OpenCascade 编译成 WebAssembly，精度与专业 CAD 一致）
- **渲染**：three.js
- **依赖**：全部本地化在 `vendor/`，**离线可用**，不联网

## 怎么用

双击 **`启动预览.bat`**，浏览器会自动打开 <http://127.0.0.1:8777/>。

手动启动：

```bash
python serve.py
```

首次加载模型要 6–12 秒（WASM 编译 + STEP 三角化），之后切换会走缓存。

## 功能

| 操作 | 说明 |
|---|---|
| 左侧勾选 | 单个看；勾多个自动并排对比，底部信息卡列出每个的外形尺寸 |
| 搜索框 | 按型号 / 文件名过滤，如 `DS3218`、`支架` |
| 等轴测 / 前 / 后 / 左 / 右 / 顶 / 底 | 标准视图 |
| 边线 | 零件棱线（结构细节最清楚的时候） |
| 线框 | 看内部构造 |
| 包围盒 | 显示外形包络框 |
| 网格 / 坐标轴 | Z 轴朝上，符合 CAD 惯例 |
| 自动旋转 | 转台展示 |
| 重载渲染 | 画面显示异常（黑屏 / 卡住）时点一下，重设画布尺寸 + 重新取景 |
| 拖入文件 | 任意 `.stp/.step/.igs/.brep` 直接拖进窗口也能看 |

鼠标：左键旋转、滚轮缩放、右键平移。

## 窗口缩放说明

页面会在窗口 / 面板尺寸变化时自动同步画布，并做了三层兜底：

1. 面板收起瞬间测到 0 尺寸时，回退到视口推算值（**不会**用 1×1 缓冲导致整屏空白）
2. 每 30 帧自检一次画布尺寸，防止 `ResizeObserver` 漏报
3. 绘制缓冲长边上限 4096，避免超大面板超出显卡上限

渲染循环用自管 `requestAnimationFrame` + 异常捕获，单帧出错不会让画面永久停住。
若仍然出现不显示，点右上角 **重载渲染**；还不行就用真实浏览器打开
`http://127.0.0.1:8777/`（预览面板对 WebGL 的支持不如独立浏览器）。

## 外形尺寸

右下角信息卡显示的 **外形 W × D × H（mm）** 就是模型的真实包围盒尺寸，
建 URDF 时可以直接拿来填杆长、舵机安装尺寸，比按图估算准。

## 换目录 / 换端口

```bash
set ARM3D_DIR=D:\别的\目录
set ARM3D_PORT=9000
python serve.py
```

或者直接改 `serve.py` 顶部的 `MODEL_DIR`。

## 为什么需要起服务

浏览器安全策略不允许 `file://` 页面读取本地文件，所以 `index.html` 必须通过
HTTP 访问，`serve.py` 就是干这个的：把模型目录挂到 `/files/`，并扫描出清单
给页面用。别双击 `index.html`，那样读不到模型。

## 目录

```
viewer3d/
├── index.html          页面与样式
├── app.js              三维渲染 / 交互逻辑
├── serve.py            本地静态服务 + 模型清单接口
├── 启动预览.bat        一键启动
└── vendor/             本地依赖（three.js + OpenCascade WASM）
```
